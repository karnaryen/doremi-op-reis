# org-ui-theme

The Doremi brand as an MUI theme: colors, fonts, shadows, component styles, for light and dark mode.

Rules for colors, tokens and contrast: [Design system](../../../README.md#design-system) in the root README. Run the tests after every color change: they check WCAG contrast.

The fonts are not loaded here. The app imports the `@fontsource` files, so they are self-hosted ([privacy.md](../../../docs/product/privacy.md)).
