# Glossary

| Term        | Meaning                                                                                                                     |
| ----------- | --------------------------------------------------------------------------------------------------------------------------- |
| Material    | A piece of music: title, sheet music, audio example, general instruction. One Material can be used for many students.       |
| Assignment  | One Material given to one student, with a personal instruction, a parent hint and a status. In the UI it is a "piece card". |
| Sheet music | A PDF or one or more images (JPEG, PNG), for example photos of the pages taken with the phone camera.                       |
| Submission  | The current recordings of an Assignment: maximum one video and one audio. Created with the first upload.                    |
| Feedback    | The teacher's latest text on an Assignment. Required when the teacher completes it or asks to try again.                    |
| Invitation  | An email with a one-time link. The parent opens it and sets a password.                                                     |
| Parent hint | A short instruction for the parent, without music terms.                                                                    |
