## Glossary

| Term        | Meaning                                                                                                                     |
| ----------- | --------------------------------------------------------------------------------------------------------------------------- |
| Material    | A piece of music: title, sheet music (PDF), audio example, general instruction. One Material can be used for many students. |
| Assignment  | One Material given to one student, with individual notes and a status. In the UI it is a "piece card".                      |
| Submission  | The current recordings of an Assignment: maximum one video and one audio.                                                   |
| Feedback    | The teacher's latest comment on an Assignment, or a "viewed" mark.                                                          |
| Parent hint | A short instruction for the parent, without music terms.                                                                    |
